# 初中英语单词背诵助手
> English Recitation Helper for Junior High School

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue.svg)]([text](https://8048519.github.io/english/))
[![License](https://img.shields.io/badge/license-MIT-green.svg)]()

一款**纯静态前端**轻量化背单词网页工具，专为初中生设计，无需后端、开箱即用，支持离线本地打开，也可部署在线访问。

## 📸 项目预览
(![alt text](https://8048519.github.io/english/thumbnail.png))

## ✨ 核心功能
- 🎲 每日抽词：随机抽取指定数量单词，一键重新抽取今日单词
- 📇 单词卡片：展示 英文单词｜音标｜词性｜中文释义
- 🙈 自测模式：一键隐藏中文释义，默写自测
- 📚 题库管理：自定义编辑、扩充单词词库
- 🖨️ A4 打印预览：生成默写试卷，支持纸质打印背诵
